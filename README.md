# ☕ Love Coffee

**Love Coffee** is a modern and responsive coffee shop website built using **HTML5** and **CSS3**. The project is designed to provide an attractive online presence for a coffee shop where customers can explore the menu, learn about the café, find its location, and get in touch.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Beautiful hero section
* About Us section
* Coffee Menu
* Fresh Coffee section
* Customer Reviews
* Contact Form
* Google Maps integration
* Modern and clean UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome
* Google Maps Embed
